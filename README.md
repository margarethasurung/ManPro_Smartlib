# SmartLib

Sistem informasi perpustakaan berbasis web untuk Mata Kuliah Manajemen Proyek.
Periode proyek: 6 November sampai 6 Desember 2026.

## Tujuan
Meningkatkan efisiensi pengelolaan perpustakaan: katalog, peminjaman dan
pengembalian, denda, pemesanan tempat, pengadaan buku, dan laporan.

## Peran pengguna
Anggota, Pustakawan, dan Manajemen.

## Teknologi
PHP (native), MySQL (phpMyAdmin), HTML, CSS, JavaScript, Figma, Git dan GitHub.

## Instalasi (lokal)
1. Clone repository ini
2. Import `database/schema.sql` dan `database/seed.sql` lewat phpMyAdmin
3. Atur koneksi database di `config/koneksi.php`
4. Jalankan lewat XAMPP atau server PHP lokal
